Кейс-задача № 3. 
Адаптировал задание под организацию, на базе которой я прохожу практику. Описал класс с именем WORKER, содержащий поля:
1.	фамилия и инициалы работника;
●	название занимаемой должности;
●	зарплату;
●	год поступления на работу.
2.	Написал программу, выполняющую следующие действия:
●	ввод с клавиатуры данных класса типа WORKER;
●	вывод на дисплей фамилий работников, чей стаж работы в организации превышает значение, введенное с клавиатуры;
●	если таких работников нет, вывести соответствующее сообщение.
Для класса предусмотрел конструктор по умолчанию, несколько конструкторов по с параметрами, деструктор, методы: изменения,
отображения полей класса и методы согласно задания. Для хранения объектов класса использовал динамический массив или стандартный список List.
Описание класса и методов класса находится в отдельном модуле.
